# Activos públicos

Coloca aquí los archivos del logo de Vacantia:

- `logo.png`        → versión horizontal (texto + isotipo). Usado en la pantalla de login.
- `logo-mark.png`   → solo isotipo cuadrado. Usado en el sidebar.
- `favicon.png`     → 32×32 o 64×64 px. Icono del navegador.

Para que se vean nítidos en pantallas retina, exporta el horizontal a **600 × 200 px** mínimo y el isotipo a **128 × 128 px** con fondo transparente.
